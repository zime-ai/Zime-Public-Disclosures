# Contribution guide

Anyone can question what is published here. Only Zime's named reviewers can publish.

## Ask a question or challenge a claim

Open an issue with the `inquiry` label. Include the artifact ID and version, the statement, and why you're asking.

## Report an error

Open an issue with the `correction` label. Include the artifact ID and version, what is wrong, and the correct information with a source if you have one.

## Suggest a source

Open an issue with a link to the source and the claim it bears on.

## Contributing as a Zime author

1. Read [content-authoring.md](content-authoring.md).
2. Work in a branch, never directly on `main`.
3. Run `npm run validate && npm run build` before opening a pull request.
4. Every material artifact needs a named human reviewer before merge.
